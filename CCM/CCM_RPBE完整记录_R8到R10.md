## 1. R10 相比 R8 的改动清单

| # | 改动 | 性质 | 触发来源 |
|---|---|---|---|
| 1 | **P0 dropout exact-replay 修复** | 训练正确性 | 审阅：官方 Step-2 LoRA 带 lora_dropout=0.05 且模型 train mode；pass1 每 microbatch 恢复同一 RNG（mask 全同）而 pass2 连续重放（mask 变化）→ z_pass1≠z_pass2、代理梯度错配。修复：pass1 记录每 microbatch RNG（pass1_rngs），pass2 三处 forward 前逐 microbatch 恢复 |
| 2 | **chain-wise 多 cut RPBE** | 训练目标结构 | 审阅：single-cut（v=k−3 单位置）只监督链上一个点，Theorem 4 要求 Σ_v D_v 全链局部缺陷和。修复：每对话对全部合法 cut v∈{0..k−3} 各产 2 horizon rows（L=13 对话 12 cut），窗口行数 256→~2000 |
| 3 | **无效监督修复** | 训练目标结构 | 用户审查：最深 cut（v=k−3）的 obs1 把上下文轮 u_{k−1} 当预测目标（上下文轮不压缩、不该被监督预测）。修复：最深 cut 跳过 obs1（只留 obs2：Y=最终目标），单行权重 1.0 |
| 4 | **rpbe-gamma-only** | 梯度路由 | 审阅：全局 r_eff=0.1 下 LoRA/COMP 稀释 RPBE 信号。修复：--rpbe-gamma-only，task 与 RPBE 双 backward 拆分，非 Γ 参数只保留纯 task 梯度 |
| 5 | **rpbe-lr 5e-5** | 优化器 | Γ 独立 AdamW 分组（LoRA/COMP 保持 3e-5），scheduler 双组同因子 |
| 6 | **λ 重校准（Γ-scope）** | 超参 | 审阅：chain-wise 改变统计尺度后旧 λ 不适用。θ0 上 Γ 组 r_eff(λ=1)=16.84 → λ=0.1/16.84=**0.00594**（R8 时代 0.0223，single-cut 全参数口径 r_eff=4.485） |
| 7 | **tree-grouped within-L shuffle 诊断** | 诊断 | 审阅：全局 shuffle 混淆深度身份（b_L 桶），within-L（同深度 cut 置换）为诚实口径；再加 tree-grouped（整对话置换）最严格版 |
| 8 | **D 自由度按 tree 分组** | 统计 | 审阅：chain-wise 后同对话多 cut 高度相关，有效样本单位是对话不是 cut；WeightedWelford 的 W2 簇改按 tree_id |
| 9 | **load_trainable fail-fast + optimizer state remap** | 工程 | missing trainable 报错（防旧 ckpt 静默留下零初始化 Γ）；单组↔双组 optimizer state 重映射（rpbe-lr 切换 resume） |
| 10 | **treewise final-spec 投影** | 保底机制 | TGN 线（feature_ablation，b523cf3 lineage）移植：行归一化 QP + 1e-6 全量证书 + CERT_FAIL skip。CCM 实测 cos_min≈−0.02 ≫ −κ=−0.05，**零介入**（与 aggregate 等价） |

## 2. 三种评估协议的定义

### 协议 C：时间步截断（主口径，官方 Table 25 同概念）
- 数据：**test 集**（clean_split=True 官方三分）；对话池 = len ≥ L+2 的对话（L=13 时 51 条）
- 构造：L = 压缩次数 ∈ {1,2,4,8,13}，每条对话截断到 L+2 轮（L 历史压缩 + 1 上下文 + 1 目标），**目标随 L 变**（第 L+2 轮）
- 聚合：**token-weighted**（ΣCE/Σtoken，官方 evaluate_perp 的 perplexity 字段同口径）
- CE：shifted + EOS 排除（eval_ce_shifted_noeos，官方 _loglikelihood_clm 语义）
- 官方数字双报：论文引用值 + 同实现复测值（发布 adapter 复现），ours 只与复测值对比

### 协议 B：pooled 五桶（官方 evaluate_perp）
- 数据：官方 DialogueDataset.eval_dataset = **val + test 合并集**（官方默认
  clean_split=False：`valset = validation + test`，eval_source="val"）——注意此处
  修正：官方评估池是合并集，不是单独 val（2026-09-17 读官方 data.py 确认）
- 构造：按对话**自然长度**分桶 turn_3/4/6/10/14（_subsample，turn_14 桶实际用 15 轮减小方差），固定前缀 [:n_turn]
- 聚合：报 `perplexity` 字段 = token-weighted；官方同时输出 loss（record-mean）但明确不报
- CE：官方 _loglikelihood_clm（EOS 排除）
- 状态：本线只跑过 EOS 修复前版本（数字作废，见 §3 存档）

### 协议 A：5L record-mean（深度曲线）
- 数据：clean **val 集** len≥15 的 **51 条**长对话（clean_split=True 三分后仅 val；
  **官方合并口径变体**：clean_split=False 的 val+test 合并池 102 条，见 §3.2b）
- 构造：每 L 取**尾端窗口** `dialog[13−L:13] + [dialog[13] 上下文] + [dialog[14] 目标]`——**目标固定为最后一轮**，只变压缩历史长度 L
- 聚合：**record-mean**（对话内 token 平均 + 全部对话等权平均）
- CE：shifted + EOS 排除
- 特性：no_ctx 在此协议下为常数（上下文+目标都与 L 无关）

## 4. 关键诊断数据

| 诊断 | R8/R9（旧结构） | R10（新结构） |
|---|---|---|
| within-L 未来信号（J_real − J_shuffled_within_L） | 0.01-0.03（噪声级） | **0.43-0.57**（提升 ~24 倍） |
| 全局口径 J_real − J_shuffled | ~0.94 | 1.74-1.91（深度桶虚高占比 97%→~70%） |
| r_Γ（Γ 组 RPBE/任务梯度比） | ~0.02 | **0.059**（gamma-only 消除稀释） |
| Gamma gate：Δlogits（loaded vs Γ=0） | — | rel_L2=0.17%、rms 5e-3；ΔNLL=-0.0004 |
| Gamma gate：100×Γ | — | ΔNLL=-0.0069（17 倍放大，接线正常） |
| ‖U^R10 − U^R9‖（s30/s20 对比） | — | 0.157（轨迹已拉开但不足以改 PPL） |
| λ 校准 r_eff（θ0、λ=1） | 4.485（single-cut 全参数） | **16.84（chain-wise Γ-scope）** |
| P0 dropout | 破坏 exact replay（未发现） | **confirmed + 修复** |
| treewise 投影 | — | cos_min≈−0.02，零介入（=aggregate） |

**核心因果链**（审阅驱动）：single-cut 稀释 → chain-wise 覆盖 → 真实未来信号 24 倍 →
r_Γ 3 倍 → P0 修复 → 协议 C 新最优（-1.2%）。但 Gamma gate 显示 Γ 对 logits 的扰动只有
0.17%（ΔNLL -0.0004）——**Γ 容量/强度是当前天花板**，结构修复已把方法带到与 R8 相当、
略有提升的水平；下一步若求实质突破，方向是 Γ 容量（head/slot/KV 分组）或 rpbe-lr 加大，
而非继续改监督构造。
