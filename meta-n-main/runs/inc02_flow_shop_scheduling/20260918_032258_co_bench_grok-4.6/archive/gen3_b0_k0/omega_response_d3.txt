```rationale
## Diagnosis
The core bottleneck for flow_shop_scheduling is the solver's strategy for n>9: it falls back to trivial sequential ordering (list(range(1,n+1))), which yields poor makespans (evident in score spread, e.g. tai20_20.txt ~0.67, tai100_20.txt as low as 0.746). Full permutations only feasible for n<=9; larger instances show massive headroom (0.205 to 1.0) because no insertion-based or constructive heuristic is used. The injected makespan helper prevents index errors but does not address the missing scheduling logic, so average remains stuck at 0.795.

## Intervention
Add solver_lib:neh_heuristic implementing the full NEH algorithm (sort by total processing time descending, then greedy insertion of each remaining job by evaluating makespan at every position). The solver will invoke it unconditionally for every instance; this directly targets flow_shop_scheduling. The solver cannot reliably derive the O(n²m) insertion loop + edge-case handling from scratch without off-by-ones or malformed sequences.

## Why this is different
Previous layer only provided textual guidance + makespan helper (solver still defaulted to permutations/sequential); this emits a complete, self-contained, reusable NEH implementation that the solver can call directly, bypassing its flawed generation logic.
```

```solver_lib:neh_heuristic
def neh_heuristic(n: int, m: int, matrix: list[list[int]]) -> list[int]:
    """NEH heuristic for flow-shop scheduling.
    Args:
        n: int — number of jobs.
        m: int — number of machines.
        matrix: list[list[int]] — matrix[i][j] = processing time of job i on machine j (0-based).
    Returns:
        list[int] — 0-based job indices in NEH order.
    """
    if n == 0:
        return []
    if n == 1:
        return [0]
    totals = [sum(row) for row in matrix]
    jobs = sorted(range(n), key=lambda i: totals[i], reverse=True)
    best_seq = [jobs[0], jobs[1]]
    for i in range(2, n):
        best_pos = 0
        best_ms = float('inf')
        for pos in range(len(best_seq) + 1):
            temp_seq = best_seq[:pos] + [jobs[i]] + best_seq[pos:]
            ms = makespan(temp_seq, matrix, n, m)
            if ms < best_ms:
                best_ms = ms
                best_pos = pos
        best_seq = best_seq[:best_pos] + [jobs[i]] + best_seq[best_pos:]
    return best_seq
```
